# React Counter App

Simple React counter app built with Vite.

## Features

- Increment counter
- Decrement counter
- Reset counter
- Clean responsive UI

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Project Structure

- `src/main.jsx` - app entry point
- `src/App.jsx` - renders the counter component
- `src/components/Counter/index.jsx` - counter logic and UI
- `src/App.css` - counter styles
- `src/index.css` - global layout and body styles

## Available Scripts

In the project directory, run:

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

To build for production:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## Notes

- The app uses React class components for the counter.
- Styles are separated between global layout (`index.css`) and component styling (`App.css`).
