# React Counter App

A simple, interactive Counter Application built with **React.js**. This project demonstrates fundamental React concepts such as state management using the `useState` hook, event handling, and clean component architecture.

---

## 🚀 Features

* **Increment & Decrement**: Increase or decrease the counter value smoothly.
* **Reset**: Instantly reset the counter back to zero.

---

## 🛠️ Tech Stack

* **Frontend**: React.js, JavaScript (ES6+), HTML5, CSS3

---
